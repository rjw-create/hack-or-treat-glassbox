Glassbox

Watch which sparse-autoencoder features fire as an open-weight language model writes, and steer them.

These are precomputed real outputs; the full tool runs locally. Every reply below was generated by Gemma 3 1B (instruction-tuned) with one Gemma Scope 2 feature pushed up, and saved by Glassbox's evaluation scripts. Nothing runs live on this page.

To explore any prompt and any feature yourself, install Glassbox and run it on your own computer.

Feature

Steering strength (feature-activation units)

Greedy decoding, 30-40 tokens per reply. "Shows behaviour" comes from a simple word-list check, so read the replies yourself. Methods and limits: results/summary.md.

Model: Gemma 3 by Google, open-weight, Gemma Terms of Use. Sparse autoencoders: Gemma Scope 2 by Google DeepMind, CC BY 4.0. Glassbox code: Apache 2.0.
