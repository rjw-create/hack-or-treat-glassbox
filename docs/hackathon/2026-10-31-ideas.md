# Open-source AI project ideas (Hack or Treat, 2026-10-31)

Target category: **Best Open-Source AI Project**. This project focuses on this one category only.

What wins: something **other people will reuse**, such as a tool, dataset, benchmark or library, with a license, clear README and easy setup. Any open model can be used.

Each idea gives: pitch, how it works, why it wins, MVP then stretch, main risk.

## O1. TRICK-OR-TREAT BENCH: do models catch the trick? (suggested pick)
- **Pitch:** an open benchmark of questions with hidden tricks: false premises ("why did Einstein win two Nobel Prizes?"), impossible requests, misleading framing. It measures whether models **spot the trick** (treat) or confidently invent an answer (trick). Includes an open leaderboard of open models.
- **Why it wins:** benchmarks shape the field, and hallucination on false premises is a real, measurable problem. The name sticks.
- **MVP then stretch:** MVP is 150 hand-checked questions, a scoring script and 3 open models compared. Stretch goals are trick categories, a web leaderboard, and a "submit your model" guide.
- **Risk:** question quality. Every question must be checked by a person, because a flawed benchmark is worse than none.

## O2. EXORCIST: remove a concept from a model and prove it is gone
- **Pitch:** a toolkit for "machine unlearning": make an open model forget a specific thing (a fictional character, a dataset, a sensitive fact), then **prove** the knowledge is gone with probing tests, while showing that general ability stays intact.
- **Why it wins:** unlearning matters for privacy and copyright, and open tools for it are scarce.
- **MVP then stretch:** MVP is unlearning one fictional concept on a small open model, with a before/after test suite. Stretch goals are several methods compared and a report card for each run.
- **Risk:** research-level difficulty. Use a small model and published methods, and be honest about the limits in the README.

## O3. VOICE LIE DETECTOR: an open detector for AI-generated speech
- **Pitch:** voice cloning is now everywhere, but good detectors are mostly closed. This builds an open, inspectable classifier that flags synthetic speech, with a simple drag-and-drop web demo and a clear report of how accurate it is and where it fails.
- **How it works:** train a small audio classifier on public spoofing datasets such as ASVspoof (check the license allows it). Publish the weights, the code and an honest evaluation.
- **Why it wins:** it fights misuse of AI with open tools, and it's timely.
- **MVP then stretch:** MVP is a trained model, a test set score and a web demo. Stretch goals are a confidence explanation and testing on new voice generators.
- **Risk:** detectors don't generalize well to new generators. The evaluation must say so plainly.

## O4. MODEL X-RAY: a transparency report for any open model
- **Pitch:** paste a Hugging Face model link and get a standard one-page report: license and what it allows, what training data is disclosed, what's missing, evaluation results, and red flags (for example "license forbids commercial use" or "no data card"). Everything is sourced from the model's own files, never guessed.
- **Why it wins:** "open" models vary hugely in how open they really are, and this makes that visible for anyone.
- **MVP then stretch:** MVP is 20 popular models scanned and rendered as reports. Stretch goals are a comparison view, a badge for READMEs, and a GitHub Action that checks a repo's model dependencies.
- **Risk:** messy, inconsistent metadata. Report "not disclosed" instead of guessing.

## O5. A11Y GHOST: an AI accessibility auditor for websites
- **Pitch:** automated accessibility checkers catch missing alt text but can't judge whether alt text is **any good**. A11Y Ghost crawls a site and uses an open vision model to judge alt text against the actual image, check whether link text makes sense out of context, and spot visual-only cues. It suggests fixes as a pull request.
- **Why it wins:** a real gap in existing open tools, a direct benefit to disabled users, and easy for others to adopt (command line plus CI).
- **MVP then stretch:** MVP is a command-line tool that scans one page and produces a report with suggested alt text. Stretch goals are a full-site crawl, a GitHub Action and automatic fix PRs.
- **Risk:** false positives annoy developers. Show confidence and let users ignore rules.

## What "open source" requires here
- A public repo with a `LICENSE` file (MIT or Apache 2.0).
- A README a stranger can follow to set up and run the project.
- Open-weight models only in the core path.
- Be precise in the pitch: "open-weight" when the weights are released but the training data and code aren't.
